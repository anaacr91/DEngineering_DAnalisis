## Plantilla SQL
Para la realización de esta tarea, debes trabajar con tecnología SQL.

Dentro de SQL, debes entrar en el subbloque indicado por el docente (parte1, parte2 o parte3) y, dentro de tu carpeta de alumno, crear un archivo por cada ejercicio.

Para la entrega de la tarea, debes:

1. Subir tu trabajo a tu repositorio en la rama `sql`.
2. Guardar tu entrega dentro de la estructura: `apellido_nombre/sql/parte1/`. Mirar readme de main como ejemplo.

Siendo:
- apellido_nombre nuestro repo
- sql la rama
- parte1 la carpeta donde irán los ejercicios. Para parte2 y parte3 la suya.

3. Nombrar los archivos con el patrón:
- `ejercicio_1.sql`, `ejercicio_2.sql`, ..., `ejercicio_N.sql`.
- También se admite `ejercicio_N.md` cuando el ejercicio sea conceptual.
4. Exportar tu entrega en un archivo zip con la nomenclatura:
- `SQL - Ejercicios (Parte II) - Apellido_Nombre.zip`.
5. Subir ese zip a la plataforma L2E.
