## Plantilla Python
Para la realización de esta tarea, debes trabajar con tecnología Python.

Dentro de python, debes crear y entrar en el subbloque fundamentos, y crear un archivo por cada ejercicio.

Para la entrega de la tarea, debes:
1. Subir tu trabajo a tu repositorio en la rama `python`.
2. Guardar tu entrega dentro de la estructura: `apellido_nombre/python/fundamentos/`. Mirar readme de main como ejemplo.

Siendo:
- apellido_nombre nuestro repo
- python la rama
- fundamentos la carpeta donde irán los ejercicios. Para unit_test la suya, para poo y para pandas otra.

3. Nombrar los archivos con el patrón:
- `ejercicio_1.py`, `ejercicio_2.py`, ..., `ejercicio_N.py`.
- También se admite `ejercicio_N.md` cuando el ejercicio sea conceptual.
4. Exportar tu entrega en un archivo zip con la nomenclatura:
- `Python - Ejercicios Fundamentos - Apellido_Nombre.zip`.
5. Subir ese zip a la plataforma L2E.
